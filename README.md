# Easyshop - Online Clothing Website

Easyshop is a full-stack MERN e-commerce platform designed to provide a hassle-free online clothing shopping experience for men, women, and kids.

## 🚀 Features
- **Dual Portals:** Separate login frameworks for Customers and Administrators.
- **Product Management:** Admin can add, update, and manage product lists.
- **Advanced Filtering:** Sorting by price thresholds (low-to-high, high-to-low) and lifestyle categories (topwear, bottomwear, winterwear).
- **Cart & Checkout:** Smooth add-to-cart operations integrated with a Payment Gateway (Stripe/Razorpay placeholder).
- **Order Tracking:** Integrated customer order history tracking and clear return request mechanics.

## 🛠️ Tech Stack
- **Frontend:** React JS, Tailwind CSS, HTML, JavaScript
- **Backend:** Node JS, Express JS
- **Database:** MongoDB

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd easyshop-clothing-website
   ```

2. **Setup Backend:**
   ```bash
   cd backend
   npm install
   # Create a .env file and configure your MONGO_URI
   npm start
   ```

3. **Setup Frontend:**
   ```bash
   cd ../frontend
   npm install
   npm run dev
   ```
